Electric Vehicle (EV) Adoption & Market Analysis Dashboard
📌 Project Overview

This project analyzes Electric Vehicle (EV) adoption trends using Power BI. It explores vehicle registrations, regional adoption patterns, and powertrain categories through interactive visualizations.

🎯 Objectives
Analyze EV adoption trends across regions.
Compare Battery Electric Vehicles (BEV) and Plug-in Hybrid Electric Vehicles (PHEV).
Identify changes in EV adoption over time.
Create interactive dashboards to present market insights.
