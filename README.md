# Electric Vehicle (EV) Adoption & Market Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze electric vehicle adoption trends, regional patterns, and powertrain categories.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Modeling
- Data Visualization

## Project Objectives
- Analyze EV adoption trends across regions.
- Compare Battery Electric Vehicles (BEV) and Plug-in Hybrid Electric Vehicles (PHEV).
- Identify market trends over time.
- Present key performance indicators through interactive visualizations.

## Skills Demonstrated
- Data cleaning and transformation
- Data modeling
- DAX calculations
- Dashboard development
- Data visualization

## Project File
The Power BI dashboard is available in this repository as a PBIX file.
